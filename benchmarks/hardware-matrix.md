# Hardware evaluation matrix

The canonical hardware matrix is maintained at [docs/hardware-matrix.md](../docs/hardware-matrix.md). This page exists at the benchmark location because earlier README text linked here.

The matrix lists evaluation strata and placement selectors; it is not proof that every platform has a working quantization kernel or has been tested. Hardware conclusions must be tied to actual benchmark results, model revisions, software versions, and the machine on which the run occurred.

See dated reports in `docs/` and `benchmarks/results/` for the scope of any recorded measurements.
